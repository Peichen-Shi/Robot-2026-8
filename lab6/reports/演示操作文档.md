# Lab6 现场演示操作文档

VMware Ubuntu 已编译好 Lab6。打开 Ubuntu 桌面终端，运行：

```bash
cd ~/lab6_complete
bash demo.sh ARUN3
```

| 屏幕位置 | 检查什么 |
| --- | --- |
| 左上图像窗口 | Office 深度图，明暗随距离变化 |
| 左下图像窗口 | 同一场景的 RGB 画面 |
| 中央 3D 窗口 | 估计位姿与真值位姿的箭头 |
| 底部 ROS Time | 时间变化表示正在播放 |

按 **Ctrl+C** 退出。把命令最后的 `ARUN3` 换成 `NISTER5`、`EIGHT8` 或 `KNOWN2` 就能切换算法，`NISTER5_RAW` 为无 RANSAC 对照。

演示话术可以这样讲：“Lab5 负责认出同一个点，Lab6 用这些点判断摄像头怎么动。二维方法主要给方向，深度让三维方法还能算移动了几米。”

| 检查点 | 在哪里找 |
| --- | --- |
| 标定与对齐 | `logs/office_evaluate.log`，记录 K、D 和实际帧数 |
| 四种方法逐帧误差 | `results/office_preview/rpe.csv` |
| 现场复算 | `bash evaluate.sh`，会输出到新的结果目录 |
| 完整版下载与验证进度 | `tail -c 700 logs/full_office.log`，初次下载进度在 `logs/office_ros2_download.log` |

当前演示回放实际测量的 Office 片段和已估计位姿。二维方法的 RViz 平移显示使用真值尺度，所有方法的显示以每个上一帧真值为起点。
