# Lab6 现场演示操作文档

**现场顺序：启动 RViz → 看画面 → 切换算法 → 查看结果 → 退出。** 已配置的 VMware Ubuntu 可以直接开始。默认回放 **2,214 对画面、约 135.40 秒**的 Office 扩展实验。

## 1. 启动演示

进入 VMware 的 **Ubuntu 桌面**，打开终端，依次执行：

```bash
cd ~/lab6_complete
bash demo.sh ARUN3
```

| 操作 | 做了什么 | 怎么确认 |
| --- | --- | --- |
| `cd ~/lab6_complete` | 进入 Lab6 实验目录 | 终端路径显示 `~/lab6_complete` |
| `bash demo.sh ARUN3` | 打开 RViz，回放原始画面和 Arun 算出的位姿 | 终端先显示 `RGB-D input` 和 `Pose input`，随后弹出 RViz |
| 看终端选中的文件 | 确认图像录包与位姿文件来自同一次实验 | 扩展版路径包含 `office_extended`，短片段路径包含 `office_verified_prefix.bag` 和 `office_preview` |

脚本优先选扩展版。扩展录包或当前方法的位姿文件缺失时，会尝试用 **213 对画面**的短片段演示。

## 2. 在 RViz 看哪里

| 位置 | 会看到什么 | 现场怎么讲 |
| --- | --- | --- |
| 左上 | 深度图 | 每个像素都有距离信息，可以把平面像点还原成空间点 |
| 左下 | RGB 图 | 无人机相机拍到的 Office 场景 |
| 中央 | 估计位姿和参考位姿的箭头 | 箭头的位置表示相机在哪里，朝向表示相机朝哪边 |
| 底部 `ROS Time` | 时间在走 | 录包正在播放 |

RViz 播放的是**已算好的位姿**。显示时用上一帧的参考位姿作为起点，二维方法的箭头长度还借用了参考移动距离。现场看误差大小时，以误差图和 CSV 为准。

## 3. 切换算法或退出

在**启动演示的终端**按 **Ctrl+C**。等提示符回来后，从表中选一条命令运行。

| 命令 | 看点 |
| --- | --- |
| `bash demo.sh NISTER5` | 五点法提出候选，再通过 RANSAC 筛掉不可靠的配对 |
| `bash demo.sh EIGHT8` | 八点法用更多配对建立线性约束 |
| `bash demo.sh KNOWN2` | 旋转已给定，两点法估计平移方向 |
| `bash demo.sh ARUN3` | Arun 用深度估计有米制尺度的位移 |
| `bash demo.sh NISTER5_RAW` | 五点法只试一次，用来和 RANSAC 对照 |

可以用一句话串起演示：“Lab5 负责找出两张图里相同的位置，Lab6 用这些点判断相机怎么动，加上深度就能算移动了几米。”

## 4. 查看统计或现场复算

只展示已有结果时，可以直接打开[实测摘要](../results/office_extended/summary.csv)、[误差图](../results/charts/README.md)和[实拍截图](../results/screenshots/README.md)。评估日志可以在 Ubuntu 里查看：

```bash
cd ~/lab6_complete
tail -n 5 logs/office_extended_evaluate.log
```

`tail -n 5` 显示日志最后五行。看到 `RGB used=2215`，表示程序用了 2,215 张 RGB 图组成 2,214 对相邻画面。

要现场重新计算，先退出 RViz，再运行：

```bash
bash evaluate.sh
```

这条命令从相邻图像重新计算五种方法。看到终端打印 `Results:` 即可去对应的新目录查看结果。原有实测资料仍放在 `results/office_extended`。

| 生成的文件 | 用途 |
| --- | --- |
| `rpe.csv` | 每对画面的匹配数、内点、求解状态和误差 |
| `*_poses.bag` | 按方法保存的估计位姿，可供 RViz 回放 |
| `evaluate.log` | 相机标定、数据量、进度和结果目录 |

## 5. 换数据或从新环境开始

| 操作 | 怎么做 |
| --- | --- |
| 换成自己的 ROS 1 录包 | 运行 `bash evaluate.sh "/绝对路径/office_ros1.bag"` |
| 回放刚算好的结果 | 运行 `bash demo.sh ARUN3 "/绝对路径/office_ros1.bag" "/绝对路径/结果目录"`。两条路径要对应同一次评估 |
| 检查录包里有什么 | 运行 `source /opt/ros/noetic/setup.bash`，再运行 `rosbag info data/office_extended.bag`，查看 RGB、深度和里程计话题 |
| 首次编译或转换课程数据 | 按[复现脚本说明](../scripts/README.md)准备 ROS、Lab5 和 OpenGV。完整 Office 录包按公告用 `rosbags==0.11.9` 转成 ROS 1 |

## 6. 常见问题

| 现象 | 怎么处理 |
| --- | --- |
| 找不到 `demo.sh` | 先运行 `cd ~/lab6_complete`，再用 `ls demo.sh` 确认脚本存在 |
| 提示 `Missing or empty input` | 按提示查看缺少的是 RGB-D 录包还是位姿包。若换了数据，先对该录包执行评估，再把输出目录传给演示脚本 |
| RViz 没弹出或画面为空 | 确认命令是在 Ubuntu **桌面终端**运行。稍等几秒，检查终端是否显示两个输入文件已打开 |
| 想结束或切换方法 | 回到启动终端按 **Ctrl+C**，等提示符出现后再运行下一条命令 |
