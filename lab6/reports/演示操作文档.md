# Lab6 · Ubuntu 现场演示

## 一条命令启动

在已经配置好的 VMware Ubuntu 桌面终端中运行：

```bash
cd ~/lab6_complete
bash demo.sh ARUN3
```

默认使用 **2,214 对画面的扩展实验**。只有短片段输入和结果可用时，脚本会切换到 213 对的短片段，并在终端显示所用的录包和位姿文件。

| 检查位置 | 看什么 | 怎么解释 |
| --- | --- | --- |
| RViz 左上 | 深度图 | 每个像素的距离信息 |
| RViz 左下 | RGB 画面 | 相机拍到的场景 |
| RViz 中央 | 估计和参考位姿箭头 | 比较同一时刻的相机位置和方向 |
| 底部 ROS Time | 时间递增 | 播放正在进行 |

按 **Ctrl+C** 退出。回放中的位姿来自实验已经算出的结果。每个估计用上一帧参考位姿作为显示起点，二维平移箭头还用参考长度显示。

## 切换方法

| 参数 | 现场怎么讲 |
| --- | --- |
| `NISTER5` | 从五对匹配点提出位姿候选，再用更多匹配检查 |
| `EIGHT8` | 用八对匹配建立线性约束 |
| `KNOWN2` | 已知相机怎么转，用两对点求平移方向 |
| `ARUN3` | 用深度把像点变成三维点，再对齐两组点来估计米制位移 |
| `NISTER5_RAW` | 五点法只提出一次假设，用来对照 RANSAC |

## 重新计算与核对

```bash
cd ~/lab6_complete
bash evaluate.sh
```

复算会打印所用输入和新结果目录。若要重跑指定录包，使用 `bash evaluate.sh /绝对路径/office_ros1.bag`。可用 `bash demo.sh ARUN3 /绝对路径/office_ros1.bag /绝对路径/结果目录` 回放对应结果。
