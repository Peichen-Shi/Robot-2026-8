## 2. 任务与场景

**任务**：桌面上摆着若干物体，机器人要自己认出每个物体属于哪一类，然后**按类分别放进左右两个料盒**。

**分类规则**（就两条，很好记）：

| 类别 | 外观 | 放在哪个料盒 |
|---|---|---|
| **A 类** | 蓝色棱柱 | 左侧料盒（LeftBin） |
| **B 类** | 红色圆柱 | 右侧料盒（RightBin） |

**场景里的 6 个固定位置**（槽位），本次交付的场景中**第 4 个位置按要求删掉了物体**，用来演示「摄像头判断这里没有东西 → 不抓取，直接去下一个」：

| 槽位 | 物体 | 坐标 (x, y, z) / m | 应该去 |
|---|---|---|---|
| 位置 1（Grid1） | A 类 蓝色棱柱 | (0.380, −1.05, 0.13) | 左料盒 |
| 位置 2（Grid2） | B 类 红色圆柱 | (0.380, +0.75, 0.13) | 右料盒 |
| 位置 3（Grid3） | A 类 蓝色棱柱 | (0.380, −0.90, 0.13) | 左料盒 |
| 位置 4（Grid4） | **（已删除，空槽位）** | — | 跳过 |
| 位置 5（Grid5） | A 类 蓝色棱柱 | (0.380, −0.75, 0.13) | 左料盒 |
| 位置 6（Grid6） | B 类 红色圆柱 | (0.380, +0.90, 0.13) | 右料盒 |

> 记法：**y 为负的一排是 A 类（蓝棱柱），y 为正的一排是 B 类（红圆柱）**；左右料盒在 x = 0.50，y = ∓0.90，箱口朝向机器人。
>
> 场景整体示意请看 `01_文档/实验三_布局图.png`（标注了料盒、槽位、地面网格与尺寸）。

**机器人**：RoboMaster EP（CoppeliaSim 官方模型，自带控制器）+ 两种“眼睛”：

- **顶部相机**（12 m 高、近似正交俯视、640×360）：负责“全场点名”——每个位置是什么类别；
- **夹爪相机**（装在夹爪前方中心、朝正前方、320×180）：负责“抓前确认”——眼前这个位置真的有物体吗？是什么？

## 3. 机器人一次完整的工作流程

```
① 顶部相机拍全场  →  识别出每个槽位的类别（A/B）与坐标
        ↓
② 底盘按直角路径（只走 X 或 Y 方向）驶到第一个目标位置前方
        ↓
③ 夹爪相机二次确认：眼前有物体吗？
        ├─ 没有（如空槽位 4）→ 不抓取，直接去下一个目标
        └─ 有 → 机械臂前伸 + 夹爪闭合到"碰到物体"为止（不压穿）
        ↓
④ 举升物体 → 底盘平移到对应料盒前方 → 机械臂下放 → 夹爪张开，物体落进料盒
        ↓
⑤ 后退一点 → 平移去下一个目标位置 → 重复 ②~④，直到所有目标处理完
        ↓
⑥（异常情况）如果目标被判定为"不可达"（两次尝试都碰不到物体）
        → 记录错误 + 立即停止任务，不再继续后面的目标
```

全过程每一步都会：**录进视频**（左上角是夹爪相机视角、右上角是识别结果）、**写进日志**（轨迹/结果/错误/汇总）、**做安全检查**（关节是否越限、有没有碰到桌子/其他物体/自己）。

## 5. 怎么跑起来（复现步骤）

### 5.1 环境要求

| 项目 | 要求 |
|---|---|
| 仿真软件 | CoppeliaSim Edu 4.10（含 ZMQ Remote API，默认端口 23000） |
| Python | 3.13 |
| Python 库 | `coppeliasim_zmqremoteapi_client==2.0.4`、`opencv-python`、`numpy`、`Pillow` |

```bash
pip install coppeliasim_zmqremoteapi_client==2.0.4 opencv-python numpy pillow
```

### 5.2 三步跑起来

1. 用 CoppeliaSim 打开场景：`03_场景/second_imitation.ttt`
2. 进入 `02_代码` 目录，**双击 `start_sim.bat`**（或执行 `python launch_sim.py`）
3. 等大约 2 分钟：机器人会自动完成 5 个物体的分类整理，结束时终端会打印每步结果与日志路径

这个 `launch_sim.py` 就是我们的 **Launch 文件**，它会自动完成：启动 CoppeliaSim 并载入场景 → 等待仿真接口就绪 → 缺少标定时自动标定 → 运行视觉分类主流程 → 汇总结果（最后可选关闭仿真）。

### 5.3 可选参数

```bash
python launch_sim.py front out.mp4 en     # 视角 front|top|side，语言 zh|en
python launch_sim.py top   none   en      # none = 只跑不录视频
python launch_sim.py --no-start           # 复用已经打开的 CoppeliaSim
python launch_sim.py --close              # 跑完自动关闭 CoppeliaSim
```

### 5.4 卡住了怎么办（常见故障）

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示端口 23000 被占用 / 连不上 | 上一次的 CoppeliaSim 或 Python 进程没退出 | 关掉残留的 CoppeliaSim 与 python 进程后重跑 |
| 仿真卡死不动 | 残留进程占用通信端口 | 任务管理器结束 `coppeliaSim.exe` 与多余的 `python.exe`，重新启动 |
| 画面文字变成「????」 | OpenCV 不能直接画中文 | 我们已改用 PIL + 微软雅黑字体渲染，无需处理 |
| 机器人不动 / 抓空 | 场景没载入或物体不在槽位上 | 确认打开的是 `03_场景/second_imitation.ttt`，并用 Ctrl+Z 复位场景 |

**几个关键设计（也是踩过的坑）：**

1. **夹爪为什么要发“信号”而不是直接设位置**：RoboMaster EP 模型自带的夹爪控制器每步都会接管 `Prismatic_joint`，直接 `setJointPosition` 会被覆盖；改成给 `gripper_link_respondable` 的整数属性 `signal.target`（1=张开 / 2=闭合 / 0=暂停）发指令才有效。详见 `01_文档/诊断结论_夹爪不动.md`。
2. **怎么判断“抓到了”**：夹爪闭合到「左右指节与目标发生碰撞」就立即停止，既确认接触，又不会把物体压穿。
3. **怎么分类**：HSV 颜色分割 + 轮廓圆度（棱柱圆度≈0.78，圆柱≈0.92），两者结合判出 A/B 类。
4. **为什么底盘只走直角**：斜线穿行时车身角会蹭到料盒外壁，改成只沿 X/Y 轴平移（配安全通道），车头与箱壁之间保留约 3.6 cm 余量。
5. **放料为什么准**：携带位姿和插入位姿不同，程序按二者之差做在线补偿，实测落位误差 ≤8 mm。
6. **夹爪相机为什么看不到机械臂**：相机装在夹爪指根前方中心、朝正前方，并按视锥做过检查，画面里不会出现机械臂。

## 10. 常见问题 FAQ

**Q1：为什么只有 5 个物体，不是 6 个？**
A：按要求删掉了位置 4 的物体，用来演示「夹爪相机判断这个位置没有物体 → 不抓取，直接去下一个目标」。相关视频：`..._位置4无物体_自动跳过_EN.mp4`。

**Q2：抓取是真“夹住”的吗？**
A：物体尺寸和夹爪开口接近，纯物理夹持不稳定，所以采用**跟随式抓取**——夹爪闭合到碰到物体后，物体与夹爪同步运动；是否“夹到”由碰撞检测确认。这是仿真中的合理简化。

**Q3：为什么有中文版和英文版视频？**
A：开发过程早期用中文界面，最终版统一改成英文界面，便于投屏/答辩展示。内容一致。

**Q4：视频为什么这么大（共约 156 MB）？**
A：视频是完整过程录像（每个约 1.5～2 分钟）。如果觉得仓库太重，可以只保留最终版 4 个，其余改为网盘链接。

**Q5：换一个场景/挪动物体后还能用吗？**
A：需要重新做一次相机标定（`vision_calibrate.py`）并更新槽位坐标；分类规则（蓝/红、棱柱/圆柱）本身不变。

**Q6：这套代码能直接控制真机吗？**
A：不能直接用。它通过 CoppeliaSim 的 ZMQ 接口控制仿真模型，真机需要换成 RoboMaster SDK 的接口。
