# 代码文件说明（实验三 · 现场演示版）

> 平时只需要双击上级目录里带【】编号的 .bat 即可，**本目录的文件不用手动改**。
> 下面这张表说明每个文件是干什么的，方便查看/答辩时对照。

## 一、运行主链路（演示时真正被调用的）

| 文件名 | 中文作用 | 关键内容 |
|---|---|---|
| `launch_sim.py` | **一键启动入口**（Launch 文件） | 启动 CoppeliaSim 并载入场景 → 等 ZMQ 接口（端口 23000）→ 检查/执行相机标定 → 调用主流程 → 汇总打印结果；支持 `--fresh`（冷启动）、`--no-start`（复用已开仿真）、`--close`，并把 `--unreachable/--noobj/--bincap/--slots` 透传给主流程 |
| `vision_pipeline_recorded.py` | **主流程**：视觉分类抓取放置 + 录制 + 日志 + 安全检查 | 6 个位置逐个处理；只用夹爪相机判断"眼前有没有物体"；抓取时夹爪闭合到刚接触物体即停；放料按位姿差在线补偿；全程录像（主画面 + 左上夹爪实时画面 + 右上识别结果） |
| `gripper_camera.py` | **夹爪相机**（抓取前判断正前方有没有物体） | 在夹爪指根前方中心创建相机（320×180，FOV 75°，朝正前方），输出识别结果与标注图 |
| `camera_node.py` | **俯视相机取图**（全场识别用） | 在 12 m 高处创建相机（640×360，FOV 12°，近似正交），输出原始帧与相机参数 |
| `detector_node.py` | **识别算法**：颜色 + 形状判类 | HSV 蓝/红分割 + 轮廓圆度判形（棱柱≈0.78 / 圆柱≈0.92），输出类别、检测框、置信度 |
| `safety_monitor.py` | **安全检查**（验收标准③） | ① 关节限位（servo_motor_0/1、Prismatic_joint）② 手臂与地面/物体碰撞 ③ 夹爪与非目标物碰撞 ④ 与车体自碰撞 |
| `sim_logger.py` | **日志记录**（验收标准⑤） | 每次运行生成 4 类文件：轨迹 CSV、结果 JSON、错误 LOG、汇总 JSON |
| `vision_config.py` | **参数配置** | 相机位置/视场、6 个槽位坐标、A/B 类别与左右料盒对应关系、HSV 阈值、圆度阈值 |
| `vision_calibrate.py` | **相机标定** | 用 6 个已知槽位做最小二乘线性拟合，求像素↔世界坐标映射（结果存 `vision_bus/calibration.json`） |
| `vision_test.py` | 视觉自检脚本 | 单独测试取图与识别是否正常 |
| `launch.yaml` | **启动描述文件**（声明式） | 用文字描述系统由哪些节点组成、各自的话题与参数，便于老师/评委核对系统构成 |
| `vision_bus/` | **消息总线目录**（模拟发布/订阅） | `calibration.json` 标定参数、`camera_meta.json` 相机内参、以及运行时产生的图像与检测 JSON |

## 二、运行时自动生成的目录

| 目录 | 内容 |
|---|---|
| `..\videos\` | 演示录像 `demo_<视角>_<月日_时分秒>.mp4`（自动命名，不覆盖旧文件） |
| `..\logs\` | 每次运行的 `trajectory_*.csv`、`results_*.json`、`errors_*.log`、`summary_*.json`，以及 `launch_*.log`（启动过程）与 `coppelia_output.txt`（仿真器自身输出） |

## 三、演示相关的命令行开关（写在 .bat 里）

| 开关 | 作用 |
|---|---|
| `front` / `top` / `side` | 录像机位：正面 / 俯视 / 侧面 |
| `auto` | 视频自动命名输出到 `videos\` |
| `zh` / `en` | 画面文字：中文 / 英文 |
| `--fresh` | 先关闭已有 CoppeliaSim，再冷启动（保证载入本文件夹的场景） |
| `--no-start` | 不启动仿真，复用已打开的 CoppeliaSim（更快） |
| `--slots=1,2` | 只处理指定位置（快速演示） |
| `--unreachable` | 把 6 号物体放到够不到的位置 → 演示"不可达 → 报错中止" |
| `--noobj` | 把桌上物体全部移走 → 演示"全部判定无物体 → 全部跳过" |
| `--bincap=N` | 把每个料盒容量设为 N → 演示"料盒已满 → 报错中止" |
| `--close` | 跑完自动关闭 CoppeliaSim |

## 四、算法要点（答辩常问）

1. **分类依据**：颜色（蓝=A 类棱柱 / 红=B 类圆柱）＋形状（轮廓圆度区分棱柱与圆柱），置信度由颜色纯度与区域尺寸加权得到。
2. **抓取判据**：夹爪持续闭合，直到"左右指节与目标发生碰撞"立即停止 —— 既确认接触，又不会压穿物体。
3. **夹爪控制方式**：RoboMaster EP 模型自带夹爪控制器会接管 `Prismatic_joint`，直接设关节位置无效；因此改为给 `gripper_link_respondable` 的整数属性 `signal.target` 发指令（1=张开 / 2=闭合 / 0=暂停）。
4. **底盘走位**：只沿 X/Y 轴平移（禁止斜线），并留安全通道，保证车头前缘与料盒外壁之间约 3.6 cm 余量。
5. **放料精度**：按"携带位姿"与"插入位姿"之差做在线补偿，实测落点误差 2~7 mm。
6. **异常处理**：目标不可达（连续 2 次闭合都没碰到物体）→ 写错误日志并中止任务；料盒满 → 同样报错中止；某位置看不到物体 → 跳过而不抓取。
