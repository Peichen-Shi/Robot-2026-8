# 实验三 · 桌面物体自动分类整理 —— 现场演示操作说明

> **双击本文件夹里带【】编号的 .bat 文件即可运行**，不需要打开命令行、不需要改任何代码。
> 想先看效果？直接双击 **【8】快速演示_只抓第1个物体.bat**（约 40 秒出结果）。

## 一、演示前 30 秒检查

| 检查项 | 说明 |
|---|---|
| ① CoppeliaSim 已安装 | `C:\Program Files\CoppeliaRobotics\CoppeliaSimEdu\coppeliaSim.exe`（脚本会自动找；找不到会提示） |
| ② Python 环境正常 | 需要 `coppeliasim_zmqremoteapi_client`、`opencv-python`、`numpy`、`Pillow`（本机已装好，可直接用） |
| ③ 端口 23000 没被占用 | 如果提示失败，先关掉所有 CoppeliaSim 窗口与残留 python 进程再双击 |
| ④ 文件夹别改名、别拆散 | 代码用相对路径找 `scene\`、`code\`、`videos\`、`logs\`，整个文件夹可以随意搬到别的盘/别的电脑 |

> 演示脚本默认会**先关闭已有的 CoppeliaSim 再冷启动**（`--fresh`），所以不管上次留下什么状态，双击就能干净开始。

| 【2】 | 俯视视角_完整分类演示 | 俯视 | 同上，从上方看底盘直角走位与料盒间距 | **267 秒**（约 4.5 分钟）※ | 抓取 5/5，成功率 100%，错误 0，安全违规 0 |

| 【4】 | 特殊情况_空槽位自动跳过 | 正面 | 先到**空槽位 4**（判定无物体→跳过），再到位置 5 正常抓取 | **52 秒** | 位置 4 跳过、位置 5 成功（1/1），错误 0 |

| 【6】 | 特殊情况_桌上无物体_全部跳过 | 正面 | 桌上没有物体：6 个位置全部判定无物体、全部跳过 | **69 秒** | 抓取 0 次、全部跳过、错误 0（正常收尾） |

> 每一次运行的落点误差都在 2~7 mm 之间（`logs\results_*.json` 里有逐物体记录），5 次抓取全部成功、安全违规 0。

## 四、推荐演示流程

**如果时间紧（3～5 分钟）**：`【8】` 看一个完整循环（50 秒）→ `【4】` 看空槽位跳过（52 秒）→ `【5】` 看异常处理（62 秒）。三个加起来约 3 分钟。

**如果时间充裕（10～15 分钟）**：`【1】` 完整流程（正面，2 分钟）→ `【3】` 侧面看姿态（2 分钟）→ `【9】` 俯视看走位（1 分钟）→ `【4】`／`【5】`／`【6】`／`【7】` 四种特殊情况（各约 1 分钟）。

**如果老师想自己动手**：先双击 `【1】`（会自动打开 CoppeliaSim 并载入场景），之后每次双击 `【0】` 就能在 38 秒内快速重跑；也可以在 CoppeliaSim 里拖动鼠标换视角观察。

## 七、出问题怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 窗口一闪而过 / 提示找不到文件 | 文件夹被改名或子目录被移动 | 保持 `code\`、`scene\` 结构与名称不变 |
| 提示端口 23000 未就绪 / 连不上 | 上次残留进程占着接口 | 关掉所有 CoppeliaSim 窗口，任务管理器结束残留 `python.exe`，再双击一次 |
| 提示未找到 coppeliaSim.exe | 安装路径不同 | 手动打开 CoppeliaSim 并载入 `scene\second_imitation.ttt`，然后双击【0】 |
| 机器人不动、报"对象查找失败" | CoppeliaSim 里打开的不是本场景 | 用 `scene\second_imitation.ttt`，或直接双击【1】（会自动冷启动正确场景） |
| 画面里物体位置不对 | 上次演示后没复位 | 每次运行脚本都会自动 `stopSimulation`→`startSimulation`，物体回到初始槽位；若仍异常，重启 CoppeliaSim |
| 想改成英文界面 | 默认中文 | 用记事本打开对应 .bat，把最后的 `zh` 改成 `en` 保存即可 |

> 郑重提示：演示过程中**不要**按 Ctrl+C 强行中断（会留下占用端口的进程）；等它自己跑完，或直接关掉窗口再双击下一个脚本（脚本会先关掉旧仿真）。

## 八、可选：命令行用法（进阶）

```bat
cd /d "本文件夹\code"
python -u launch_sim.py front auto zh --fresh              :: 正面视角，中文界面，冷启动
python -u launch_sim.py top   auto en --fresh --slots=1,2  :: 俯视视角，英文界面，只抓前两个
python -u launch_sim.py front auto zh --fresh --unreachable --slots=5,6
python -u launch_sim.py front auto zh --fresh --noobj
python -u launch_sim.py front auto zh --fresh --bincap=1 --slots=1,2,3
python -u launch_sim.py front auto zh --no-start           :: 复用已打开的仿真（更快）
```

| 参数 | 含义 |
|---|---|
| `front` / `top` / `side` | 录像机位视角：正面 / 俯视 / 侧面 |
| `auto` / 具体路径 | 视频输出位置（`auto` = 自动命名放进 `videos\`） |
| `zh` / `en` | 画面文字语言：中文 / 英文 |
| `--fresh` | 先关闭已有 CoppeliaSim 再冷启动（保证正确场景） |
| `--no-start` | 不启动仿真，复用已经打开的 CoppeliaSim |
| `--close` | 跑完自动关闭 CoppeliaSim |
| `--slots=1,2` | 只处理指定位置（快速演示） |
| `--unreachable` | 把 6 号物体放到够不到的位置（演示"不可达→中止"） |
| `--noobj` | 把桌上物体全部移走（演示"全部跳过"） |
| `--bincap=N` | 把每个料盒容量设为 N（演示"料盒已满→中止"） |
