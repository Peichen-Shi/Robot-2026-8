# 小车移动 测试结论（2026-09-10 实测，场景 second_imitation.ttt）（最终版）

> **文档版本：最终版**（定稿 2026-09-10）｜ 实验三 桌面物体自动分类整理（CoppeliaSim 仿真）

## 结论

1. **车轮物理驱动真实可用**（4 个全向轮，各自带“滚筒复位”子脚本）：
   - 4 轮同向 → 平移（实测 3s 前进 1.13m）
   - 左/右差速（FL,RL 一组 / FR,RR 反向）→ 原地旋转，漂移 < 1cm
   - 对角组合（FL,RR 一组 / FR,RL 反向）→ 横移（全向轮运动学）
2. **平移用“小步传送”最可靠**：setObjectPosition 插值，位置精确、朝向不变
   （每步 resetDynamicObject 会破坏轮子状态，不要用；直接纯传送即可）
3. **转向用“车轮闭环”最可靠，但只在“本轮仿真未做过传送”时灵**：
   - 起点直接转：1.3s 转 90°，漂移 1mm ✅
   - 传送 1m 后再转：轮子打滑/卡滞，转不动 ❌（疑似传送破坏动态接触状态，待查）
   - setObjectOrientation 传送转向：会把车“蹭”跑/翻滚 ❌
   - 悬空转向、pause 中传送：都被动力学/插件干扰 ❌

## 实用策略（供完整流程用）

- 车辆朝向用**每次 startSimulation 后的初始朝向**（场景存档 ~106.9°），
  不依赖“运行中转向”；
- 路径只用**平移传送**（任意 (x,y)，精确）；抓取是跟随式假抓取，
  不需要严格对向，因此可行；
- 若必须转向：先不传送，在起点用轮子转到目标朝向，再传送执行任务。

## 关键实测数据

| 操作 | 结果 |
|---|---|
| 4轮同向 +3，3s | +1.13m，yaw 基本不变 |
| 差速 (3,-3,3,-3)，2s | yaw -198°，位移 <1cm |
| 对角 (2,-2,-2,2) | 横移 0.42m |
| 起点车轮转向 90°（闭环） | 1.3s，漂移 1mm |
| 纯传送前进 1.0m（无 reset） | 精确 +1.0m，yaw 不变 |
| 传送后再车轮转向 | 失败（卡滞） |
