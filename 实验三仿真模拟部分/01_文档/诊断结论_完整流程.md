## 流程（每个物体一次循环）

1. 归位：机械臂 home + 夹爪 OPEN
2. 机械臂下降到抓取姿态（s0=+30°），实测"夹爪前伸偏移" = (+0.173, -0.008)
3. **开车**：车体目标位置 = 物体坐标 − 前伸偏移（小步传送，精确无漂移）
4. **抓取**：记录 offset = 物体中心 − 手指中点（实测约 (0,-0.0003,-0.0234)）
5. **抬升**：s0=-25°，抬升过程中每步同步物体位置（跟随式抓取）
6. **开车去分类箱**：目标位置 = 投放点 − 前伸偏移，行驶途中持续同步物体
7. **放下**：机械臂下降回 +30°，解除跟随，把物体放到箱内 (x, y, 0.13)
8. 归位，进入下一个物体

## 关键前提（为什么稳）

- 场景里 Grid 与分类箱都是 `static=1, respondable=0` 的**视觉件**，互不碰撞 →
  车体可以直接滑过/穿过物体堆，全程不会物理爆炸（这是流程能一次跑通的关键）。
- 每次操作前显式把物体设为 `static=1, respondable=0`（因为停止仿真后物理属性不会自动恢复）。
- 全程不做运行中转向，靠"固定朝向 + 平移传送"导航。

## 分类箱几何（实量）

- LeftBin 内腔中心 (0.38, -0.90)；RightBin 内腔中心 (0.38, +0.90)
- 箱底 z=0.01，投放时物体中心取 z=0.13（物体高 0.22，刚好落在箱底）
- 箱内 x 方向按 -0.13 / 0 / +0.13 错开，3 个物体不重叠
