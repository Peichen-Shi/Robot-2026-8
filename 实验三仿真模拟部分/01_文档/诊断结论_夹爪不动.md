# 夹爪不动 — 诊断结论与修复记录（2026-09-10 实测）（最终版）

> **文档版本：最终版**（定稿 2026-09-10）｜ 实验三 桌面物体自动分类整理（CoppeliaSim 仿真）

> 场景：`second_imitation.ttt`；CoppeliaSim Edu 4.10；ZMQ Remote API 端口 23000；
> Python 3.13 + coppeliasim_zmqremoteapi_client 2.0.4。

## 一、结论（一句话）

`Prismatic_joint` 是**动态关节 + 模型自带夹爪控制器脚本(挂在 `gripper_link_respondable` 上)每步接管**，
所以 Python 的 `setJointPosition / setJointTargetPosition` 被顶回，位置钉在 ~0.0007（= 控制器 open 上限 0.00098≈0.001）。
**正确做法是给控制器发状态命令（int 属性信号），而不是抢关节。**

## 二、证据链

| 测试 | 结果 | 结论 |
|---|---|---|
| 仿真停止，写 -0.025 | 位置变 -0.023（区间下限） | 负向物理可达 |
| 仿真停止，写 +0.05 | 位置只到 0.001 就被顶住 | 正向上限 ≈0.001（手指联动机构锁死）|
| 仿真运行 + 写 target ± | 位置恒为 ~0.001 | 有东西每步覆盖/归零 |
| 关掉全部子脚本再写 | 位置 ±0.0003 漂移，仍不跟随 | 还有动力学本身在接管（电机开、无位置环）|
| 读夹爪控制器脚本源码 | `min=-0.0229, max=0.00098`，`setJointTargetVelocity(h, ±0.01)` | 控制器按速度模式驱动关节，正是覆盖源 |

关节参数（实测）：
- `getJointInterval` = [-0.023, 0.024] m（注意：不是 Lua 里的 ±0.05/0.025，写入超界会被截断）
- `jointintparam_motor_enabled` = 1，`jointintparam_ctrl_enabled` = 0（电机开、无位置控制环）
- 控制器状态机：`State.pause=0 / open=1 / close=2`，信号 `signal.state`(当前)、`signal.target`(命令)，均挂在 `gripper_link_respondable` 的 int 属性上。

## 三、修复：夹爪原生信号接口（已验证真实开合）

```python
grp = sim.getObjectParent(sim.getObject("/Prismatic_joint"))  # gripper_link_respondable
sim.setIntProperty(grp, "signal.target", 1)   # 1=OPEN
# 轮询直到 sim.getIntProperty(grp, "signal.state") == 1
sim.setIntProperty(grp, "signal.target", 2)   # 2=CLOSE
# 轮询直到 state == 2
```

实测（`gripper_min_test.py` 输出）：

| 动作 | Prismatic_joint | 左右手指间距(L5) |
|---|---|---|
| OPEN | +0.00100 | 0.11744 m |
| CLOSE | -0.02299 | 0.02998 m |

手指间距 0.03 ↔ 0.117 m，**真实动作**。

### 额外红利
close 时控制器会用接近传感器 + 碰撞检测扫描两指间的物体，
命中后执行 `setObjectParent(物体, attachPoint, true)` **自动抓取**（会打印 `Attached shape`）。
这正是"仿真实抓取"的模型原生方案——后续 Grid1 抓取优先考虑用它，而不是手指坐标跟随。

## 四、必须注意

1. **模型脚本必须保持启用**：夹爪控制器是脚本(h≈91 on gripper_link_respondable)驱动的，禁用后信号接口失效。
2. `/RoboMaster` 子脚本里有 `simRobomaster.create_ep(...)`（每个仿真周期 init 执行一次）。
   我们自己的代码**不要**再调 create_ep（会注册完整控制器、锁关节）。它与本次信号接口测试无冲突。
3. Lua 参考代码里的 GRIPPER_OPEN=0.05 / CLOSE=-0.025 在本场景**不可直接用作关节位置**（区间只有
   [-0.023, 0.024]），但语义一致：open≈+0.001（张）、close≈-0.023（合）——以控制器信号为准，数值不用自己填。
4. 场景里没有 `Cylinder`，只有 `Grid1..Grid6` + 左右分类箱；Lua 成功 demo 是另一个场景（对象名不同），
   控制思路（信号/脚本接管 vs 直接写关节）不能盲目照搬。
